# GGB TV

Быстрый домашний экран без рекламы для Android TV и Google TV. Сделан под Xiaomi Mi Box S (2-е поколение), но
работает на любой приставке или телевизоре с Android 8 и новее.

Основан на [Free My TV](https://github.com/simbasjungles/free-my-tv) (лицензия MIT). Из оригинала регулярно
подтягиваются улучшения, а свои отличия остаются.

## Что внутри

- **Без рекламы и рекомендаций.** Никаких рядов «спонсоров», баннеров и автозапуска роликов. Только ваши приложения.
- **Полка-карусель.** Сколько угодно приложений, порядок задаётся на самом ТВ. Можно включить порядок по
  последнему запуску. В конце полки всегда есть плитка «Все приложения».
- **Верхние кнопки.** Настройки, Wi-Fi, Bluetooth, смена темы, входы, «Недавние», магазин: до пяти кнопок на выбор.
  Порядок меняется удержанием OK.
- **Погода.** Прогноз по часам или на 5 дней, восход и закат. Работает и там, где основной сервер open-meteo
  недоступен: используются запасные адреса.
- **Курсы валют.** Доллар, евро и юань по курсу ЦБ РФ.
- **«Сейчас играет».** Что звучит или показывается на ТВ, на месте котировок.
- **«Продолжить просмотр».** Фильмы и серии, которые вы не досмотрели, из приложений, которые это поддерживают.
- **Таймер сна.** Через выбранное время переводит ТВ в режим сна.
- **Недавние приложения.** Последние открытые приложения в боковой панели.
- **День и ночь.** Тема переключается по реальному закату в вашем городе. Мягкий фон и шрифт Nunito.
- **Безопасно.** Без root, ничего не удаляется. Одной кнопкой возвращается заводской экран.
- **Автообновление.** Раз в неделю проверяет релизы этого репозитория и предлагает поставить новую версию.

## Установка

Нужны приставка или ТВ на Android 8+ и компьютер в той же сети Wi-Fi с
[adb](https://developer.android.com/tools/releases/platform-tools) (Android SDK Platform-Tools).

1. **Включите отладку на ТВ.** Откройте Настройки → Настройки устройства → Об устройстве и нажмите «Сборка» 7 раз.
   Затем в Настройки → Настройки устройства → Для разработчиков включите **Отладку по USB**. IP-адрес ТВ можно
   посмотреть в Настройки → Сеть и Интернет.
2. **Скачайте `GGB-TV.apk`** из [последнего релиза](https://github.com/Genrihbag/ggb-tv/releases/latest).
3. **Установите** (подставьте свой IP):
   ```bash
   adb connect 192.168.1.50:5555
   adb install -r GGB-TV.apk
   ```
   На ТВ появится запрос на отладку: отметьте «Всегда разрешать» и нажмите OK.
4. **Включите.** На ТВ откройте *GGB TV* → *Главный экран* → *GGB TV*. Приложение само отключит заводской
   экран и заставку. Если ТВ снова спросит про отладку, разрешите.

Город по умолчанию — Краснодар. Свой город задаётся в *Настройки экрана* → *Город*.

## Обновления

Сборка из релизов подписана ключом проекта и обновляется сама. Раз в неделю она смотрит
[релизы](https://github.com/Genrihbag/ggb-tv/releases), скачивает новую версию, проверяет размер, контрольную сумму
и подпись, а затем предлагает установить её через установщик Android. Проверить вручную можно в
*Настройки экрана* → *Обновления*.

Версия, собранная на своём компьютере с другим ключом, о новой версии только сообщает. Поставить её поверх
не получится, пока не удалите свою.

## Настройки

Всё настраивается на самом ТВ:

- *GGB TV* → *Настройки экрана*: язык, температура, тема, часы, фото, звуки, верх экрана, «Продолжить
  просмотр», погода, город, прогноз, «Сейчас играет», курсы валют, обновления.
- *GGB TV* → *Избранные приложения*: что стоит на полке и в каком порядке.
- *GGB TV* → *Верхние кнопки*: какие кнопки над полкой.
- *GGB TV* → *Таймер сна*.

## Как вернуть заводской экран

На ТВ: *GGB TV* → *Главный экран* → *Заводской*. Заводской экран, заставка и всё, что было отключено, вернутся как
были. Если новый экран упадёт три раза за пять минут, приложение само переключится обратно.

Чтобы удалить GGB TV совсем, сначала переключитесь на *Заводской*, затем удалите приложение в Настройки →
Приложения.

## Что меняется на ТВ

- GGB TV становится домашним экраном и заставкой.
- Без удаления отключаются заводской домашний экран и заставка, а на Xiaomi ещё PatchWall и сопутствующие сервисы.
  Список отключённого хранится в настройках ТВ, и *Заводской* возвращает всё по нему.
- Для «Продолжить просмотр» выдаётся разрешение `READ_TV_LISTINGS` через ADB самого ТВ. *Заводской* забирает его
  обратно.
- Изображение, звук, входы, пульт, сервисы Google и Play Маркет не трогаются никогда.

## Сборка

Без Gradle, одним скриптом. Нужны JDK 17+ и Android SDK (build-tools 34+, platform android-34). На Windows
запускайте в Git Bash:

```bash
export ANDROID_HOME=~/Android/Sdk
bash build.sh
adb install -r FreeMyTV.apk
```

Первый запуск создаёт `config.properties` (город, координаты, язык) и ключ подписи `freemytv.keystore`. Оба
файла в git не попадают. Ключ храните: обновления ставятся только поверх версии с тем же ключом.

### Релиз

Релизы собирает GitHub Actions, и только по ручному запуску. Настройки и ключ подписи берутся из секретов
репозитория `CONFIG_PROPERTIES` и `KEYSTORE_B64`.

1. Поднимите `versionName` (дата, например `2026.11.13`) и `versionCode` (`2026111300`) в
   `app/AndroidManifest.xml`.
2. Запустите workflow с названием релиза `v` + versionName:
   ```bash
   gh workflow run APK -f release=v2026.11.13
   ```
   ТВ с GGB TV найдут релиз сами.
